# Transcriptor

Transcribe tus videos y audios a texto en tu propia PC (con la tarjeta de video si tienes una NVIDIA),
agrúpalos en sesiones y pídele a Claude resúmenes y pendientes.

## Descargar

1. Entra a **[la última versión](https://github.com/kaiomar4321/transcriptor-releases/releases/latest)**
   y descarga `Transcriptor_<versión>_x64-setup.exe`.
2. Ábrelo. Windows dirá «Windows protegió su PC» porque la app no está firmada:
   **Más información → Ejecutar de todas formas**.
3. La primera vez la app descarga su motor de transcripción (≈ 4 GB con GPU NVIDIA, ≈ 2 GB sin ella).

Para los resúmenes conecta **tu propia** cuenta de Claude (Pro o Max) o tu propia API key desde la
pantalla de bienvenida o en Ajustes → Claude.

Cuando haya una versión nueva, la app te avisa sola y se actualiza con un clic.

Requisitos: Windows 10 u 11 de 64 bits.
